# The 3-Phase Builder Process

An interactive, click-through explainer of the 3-Phase Builder Process: the Plan to Build to Learn loop with its seven nested steps. Built as a single self-contained HTML file. No build step, no dependencies, light and dark mode included.

## Run locally

Open `index.html` in any browser. That's it.

## Deploy

This is a static site. Drag the folder into Vercel, or connect this repo to Vercel and it deploys automatically. No framework preset or build command needed.

## The loop

- **Plan** sets the AI up to succeed before it writes a word: Prompt Framework, Scope & Specify.
- **Build** runs a tight loop until the output matches the goal: Create, Review, Feedback.
- **Learn** turns the finished build into something that makes the AI smarter next time: Skillify, Log.

It's a loop, not a line. What you learn at the end of one build feeds the start of the next.
